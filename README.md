# PH — Artigos sobre Design Visual

Coletânea de artigos sobre princípios de percepção e composição visual aplicados a design de interfaces. Cada artigo combina fundamentação teórica (Gestalt, atenção, carga cognitiva) com aplicação prática e olhar crítico sobre o que tem base científica e o que é convenção.

## Como este repositório é organizado

```
ph-artigos/
├── index.html             (site — leitor de artigos)
├── assets/                (styles.css, app.js, content.js)
├── README.md              (este arquivo — índice)

```

## Site

O conteúdo também é publicável como site estático (`index.html`), com leitor de Markdown, sumário automático por artigo e tema claro/escuro. Basta servir a pasta por HTTP ou publicar no GitHub Pages.
